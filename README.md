# Компаратор текстовых файлов

**Вариант:** 16

**Описание:** Консольное приложение на Java для сравнения двух текстовых файлов. 
Поддерживает два режима: построчное и посимвольное сравнение.

## Структура проекта

- `FileComparator.java` — основная логика сравнения.
- `ComparisonMode.java` — перечисление режимов сравнения.
- `FileCompareException.java` — собственное проверяемое исключение.
- `TextComparatorApp.java` — консольный интерфейс.

1. Скомпилировать все файлы:
   ```bash
   javac *.java
